# 🚀 Rocket.Q React

A fullstack Q&A (Question and Answer) application where users can create rooms, submit questions, and interact with content in an organized way.

---

## 📌 About the project

This is a fullstack Q&A (Question and Answer) application built with modern web technologies such as JavaScript, React, Node.js, and PostgreSQL.

The application allows users to create rooms, submit questions, mark them as answered, and delete them. It also includes authentication mechanisms to protect sensitive actions.

---

## 🧠 Features

- Create rooms with a unique code
- Join rooms using a code
- Submit questions
- Mark questions as answered
- Delete questions
- Delete rooms with authentication
- Basic authentication for protected actions
